# 🧮 python-cli-calculator

My first Python project - built 20 days BEFORE starting BTech in AIDS at Zeal College of Engineering, Pune.

Fully coded on phone using Pydroid 3, no laptop.

### ✨ Features
- Addition, Subtraction, Multiplication, Division
- Loop with `while True` - keeps running
- Handles errors (div by zero)
- Clean CLI interface

### 📱 Built On Phone
Tool: Pydroid 3
Biggest issue solved: `IndentationError` - fixed using Tab key (not spaces)

### 🚀 How to Run
1. Open Pydroid 3
2. Paste code from `calculator.py`
3. Run

I wanted to start coding before college starts (17 Sept). This is Day 1.
